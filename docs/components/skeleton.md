# Skeleton

Marcador de carregamento com o formato do conteúdo que vai chegar. É o `Skeleton` do shadcn/ui.

## O que você fornece
- Dimensões via classes (`h-4 w-[220px]`, `size-10 rounded-full`), espelhando o layout final.
- Use para carregamentos acima de ~300ms. A animação para com `prefers-reduced-motion`.
