# Switch

Liga/desliga uma configuração com efeito imediato. É o `Switch` do shadcn/ui (Radix).

## O que você fornece
- `id` + `Label`; `checked` / `onCheckedChange`.
- O label descreve a configuração, não a ação: "Notificações por e-mail", não "Ativar notificações".
- Se a mudança só vale após "Salvar", use `Checkbox`.
